# Revelation Youth

The website for the youth ministry of International Miracle Makers Church, built around its theme, **"Just a Moment With God."** It gives the ministry one home for its music, events, devotions, merch, and community.

## Features

- **11 pages:** Home, Music (including the *Encounter* release, with a page for each track), Events (worship nights, youth services, and conferences), Devotions, Merch, and Community.
- **24 reusable React components.** Page content lives in typed data files under `src/data/` instead of being hard-coded into components.
- **Light and dark themes,** with a toggle.
- **Responsive layouts** for phones, tablets, and desktops.

## Tech stack

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS, next-themes, and lucide-react icons.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

Live at https://revelation-youth.vercel.app (deployed on Vercel).
